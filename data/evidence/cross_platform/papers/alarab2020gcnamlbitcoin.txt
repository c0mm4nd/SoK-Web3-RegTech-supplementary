ABSTRACT (near-verbatim from publisher landing + Bournemouth eprint):

"Graph networks are extensively used as an essential framework to analyse the interconnections between transactions and capture illicit behaviour in Bitcoin blockchain. Due to the complexity of Bitcoin transaction graph, the prediction of illicit transactions has become a challenging problem to unveil illicit services over the network. To address this problem, this work presents a novel approach modelled using the existing Graph Convolutional Network intertwined with linear layers. Briefly, we concatenate node embeddings obtained from graph convolutional layers with a single hidden layer derived from the linear transformation of the node feature matrix and followed by a Multi-layer Perceptron. The proposed approach has been evaluated using Elliptic data, the time series of Bitcoin transaction graph, which outperforms the original work that has been previously evaluated on the same dataset."
